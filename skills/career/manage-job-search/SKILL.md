# Manage Job Search

Keep the search focused, current, and recoverable across sessions.

## Maintain durable context

1. Locate an existing career context file or create one in the user's chosen private workspace. Never place personal candidate data in a public skill repository.
2. Preserve verified candidate facts, preferences, boundaries, application history, resume variants, contacts, and pending actions.
3. Record sources and dates for changing facts such as open roles, compensation, work models, and application limits.
4. Update status immediately after an application, outreach message, response, withdrawal, or role closure.
5. Avoid duplicating applications or recommending closed, rejected, or intentionally deferred roles.

## Choose the next action

1. Review active opportunities, deadlines, warm contacts, outstanding follow-ups, and search constraints.
2. Separate urgent actions from high-value actions. Do not confuse application volume with progress.
3. Prioritize in this order unless the user directs otherwise:
   - time-sensitive high-fit applications
   - warm referrals or targeted outreach
   - interview preparation for active processes
   - selective role discovery
   - resume or portfolio improvements with clear reuse value
4. Recommend a short next-action queue with rationale.
5. Respect application-frequency limits, relocation boundaries, compensation needs, and the user's preferred risk/reward balance.

## Context model

Read [references/context-model.md](references/context-model.md) when creating or restructuring durable search context.

Do not submit applications, send outreach, or disclose personal data without the authority required for that action.
