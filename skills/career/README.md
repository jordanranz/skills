# Career

Skills for professional development, job search, interviewing, and positioning.

- [`resume-refinement`](resume-refinement) — tailor and verify resumes without stretching the facts.
- [`evaluate-role-fit`](evaluate-role-fit) — compare opportunities against verified experience, goals, and constraints.
- [`refine-application-response`](refine-application-response) — interview for and refine authentic application answers.
- [`manage-job-search`](manage-job-search) — maintain a selective pipeline and durable private search context.

## Suggested flow

1. Use `manage-job-search` to choose the next opportunity.
2. Use `evaluate-role-fit` to decide whether it deserves time.
3. Use `resume-refinement` for the smallest useful resume pass.
4. Use `refine-application-response` for authentic written responses.
