# Evaluate Role Fit

Make a selective, evidence-backed recommendation rather than a keyword-match score.

## Evaluate a role

1. Read the live official posting when available. Record the title, team, location, work model, compensation, responsibilities, and qualifications.
2. Read the candidate's source resume and durable career context. Separate verified facts from assumptions.
3. Extract five to eight success factors. Weight actual responsibilities and hard requirements above generic qualifications.
4. Map candidate evidence to each factor using the rubric in [references/fit-rubric.md](references/fit-rubric.md).
5. Evaluate non-skill constraints independently: level, location, work model, compensation, risk, product interest, application limits, and timing.
6. Identify the strongest evidence, material gaps, likely screening risk, and what would need clarification.
7. Recommend one outcome:
   - `Prioritize`: strong evidence and acceptable constraints.
   - `Selective`: credible upside with one or two meaningful risks.
   - `Skip`: weak core evidence, unacceptable constraints, or poor opportunity cost.
8. Recommend the base resume, an existing variant, or the smallest useful tailoring pass. Do not edit unless requested.

## Comparison rules

- Compare roles on the same dimensions and evidence standard.
- Do not let employer prestige erase a weak role match.
- Treat personal interest as a valid factor but keep it distinct from demonstrated qualification.
- State uncertainty when location, compensation, team scope, or posting status is unclear.
- Prefer current official sources for facts that can change.

## Output

Lead with the recommendation. Follow with strongest fit, largest risk, constraint check, and next action. Use a compact comparison table only when evaluating three or more roles.
